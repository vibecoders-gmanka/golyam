# Морской бой

Этот репозиторий содержит две версии игры "Морской бой" на Python:

- **Текстовая** (`battleship.py`) — простая консольная версия
- **Pygame** (`battleship_pygame.py`) — игра с графическим интерфейсом и сетевым режимом

## Запуск текстовой версии

1. Убедитесь, что у вас установлен Python 3.
2. В терминале перейдите в папку репозитория.
3. Выполните команду:

```bash
python3 battleship.py
```

## Запуск версии на Pygame

1. Установите зависимости:

```bash
pip install pygame
```

2. Чтобы создать игру и ждать подключения соперника, запустите:

```bash
python3 battleship_pygame.py --host --port 65432
```

3. Чтобы подключиться к уже запущенной игре, выполните на другом компьютере или в другой консоли:

```bash
python3 battleship_pygame.py --connect <ip_хоста> --port 65432
```

4. После подключения откроется окно с двумя полями. Слева ваше поле, справа поле соперника. Кликайте по клеткам на правом поле, чтобы стрелять.

## Общие правила

- Поле состоит из сетки 5x5.
- Каждый игрок имеет три однопалубных корабля, размещённых случайно.
- Побеждает тот, кто первым поразит все корабли соперника.

Удачной игры!
